## 公共行为与兼容

后端状态、节点导入/刷新、Bridge 启动、浏览器启动、日志与 WebDAV 被 Web、macOS、托盘和 Docker 共同复用。新增字段保持 JSON 状态文件兼容，不改变已有原子保存与备份格式；旧状态缺失收藏、备注、健康和测速历史字段时按默认值读取。没有过滤规则时继续全部导入，订阅刷新保留核心偏好与个人标记。

共享认证仅在新开启且未显式指定方式时生成 Token；既有启用的无认证设置保持原样，修改其他安全字段不隐式关闭认证。普通状态不包含 Token 或密码原文，新生成 Token 只在保存响应中返回。认证仍允许显式 Basic、Token 或 none。

自动切换默认关闭，已绑定浏览器记录的源节点与目标节点都不参与；开始前及核心预检后再次验证地区、结果新鲜度与绑定状态。切换复用原端口，失败尝试恢复；现有普通启动仍保留原来的空闲端口选择逻辑。浏览器出口自检失败不改变浏览器启动成功的响应，不回退直连。

状态流沿用实例请求头认证。轮询兜底继续可用，后台更新不会重建正在编辑的行；订阅、运行代理与浏览器记录同样使用稳定 key。WebDAV 预览只读，不返回节点凭据或订阅完整 URL；拉取再次核验预览哈希，并保留已有的本地并发与运行 Profile 保护。

## 实际检查

- Python 3.12 全套：404 项，结果为 OK，4 项根据 OpenSSL 可用性条件跳过；单独执行 WebDAV 套件 54 项全部通过，无跳过，覆盖加密往返与预览。
- Node 内置测试：34 项全部通过；全部普通脚本、页面模块与 `main.mjs` 入口通过语法检查。
- 浏览器：11 个入口无脚本错误；1440×900 紧凑模式实际行高 36px，可见 19 行；960 / 720 / 520px 无页面水平溢出，每页主按钮至多一个，最小文字为 11px。
- 1000 节点：紧凑 36px、标准 44px、520px 卡片均可到达最后一条，挂载记录不超过 32 行。
- 交互：SSE 更新保留抽屉草稿和焦点；真实 DOM 排序、展开菜单、延迟删除与空列表检查通过。事件接口持续失败时，8 秒内仍完成 3 次状态请求。
- 批量启动：模拟 API 验证正确启动路径、部分失败继续执行和结果汇总；最快多个节点排除缺失延迟，缺失值不显示为 0ms。
- 设置：960×600 下保存条位于屏内，放弃可还原草稿，一次保存网络、测速、日志三个分区后清除 dirty 状态。
- 多语言：控件切换为 English 后，自定义节点名、订阅名和浏览器标签保持原文；切回中文不误改用户文本。
- 静态检查：`git diff --check`、Shell 语法、Swift 语法解析、工作流 YAML 解析、CSS token 引用、颜色与字号检查通过。当前 Python 环境无 PyYAML，工作流使用 Ruby 标准 YAML 解析器检查。

## 验证边界

Python 测试使用隔离临时目录和模拟服务；浏览器检查使用独立临时 Profile 与虚拟订阅，不修改已有用户数据。

本机验证不能替代真实订阅、代理核心启动、指纹 Chromium、外部出口服务、生产 WebDAV 服务器或 Docker Broker 的端到端验证。Windows / Linux 安装包、Docker 镜像及 macOS 完整发布包没有在本次验收中构建；macOS 源码做语法解析检查。实际大批量启动、持续并发、真实网络耗时和多设备同步性能仍需在对应环境验证。

错误数量仅针对当前日志缓冲区，服务重启或内存日志轮换后不补算已丢失历史。网关分配统计属于本次网关运行周期。操作、配置及安全边界详见 [控制台工作区](console-workspace.md)。
