# 控制台工作区

控制台沿用 Python 标准库后端与原生前端，无需安装前端框架或执行打包命令。macOS、托盘、普通浏览器与 Docker 使用同一份静态界面。

`static/main.mjs` 是原生模块入口，页面渲染拆到 `static/pages/`；公共模块保留 Node 测试兼容。样式入口按 tokens / components / pages 三层加载，颜色和字号集中在 `tokens.css`，打包仍递归携带整个静态目录。

## 使用路径

从概览进入订阅，添加 URL 或原始内容。导入前可预览包含、排除规则命中的节点；关键词以逗号或换行分隔，正则模式每行一条。排除规则优先。正则不支持嵌套重复、重复分组内分支或回溯引用，避免过滤阻塞服务。

节点页提供运行、可用、失败、未测试分段。测速结果按延迟着色，过期结果单独标记。选择节点后使用批量操作；节点名称打开详情，其中可修改核心、回退、地区、收藏和备注，查看浏览器记录及最近 20 次测速。收藏、备注与手动地区覆盖在订阅刷新后保留，参与 WebDAV 同步。

运行中代理页用于复制端口与代理地址。代理池和智能网关独立管理；网关已有连接固定在建立连接时选中的节点，策略更改仅作用于后续连接。网关的分配统计在本次网关启动期间累计。

指纹浏览器记录集中展示最近使用情况。浏览器启动后通过绑定的本地代理访问 `https://ipwho.is/` 检查出口 IP 和国家代码；请求失败不会回退直连。自检结果用于提示地区不一致，不能替代 WebRTC 或 DNS 检查。

## 配置与兼容

- 表格密度默认紧凑（36px），标准为 44px；主题、语言和密度为本浏览器的界面偏好。
- 新开启局域网共享且没有显式选择认证时使用自动生成的 Token。Token 仅在保存响应返回一次，常规状态不返回秘密；请及时复制保存。已有启用的无认证共享不会在升级后自动改变，前端新选择无认证需要确认。
- 运行探活每 60 秒通过核心回环端口访问已有测速目标，最多三路。失败会更新健康状态、代理池健康记录和系统日志；受目标站点故障影响，探活失败不一定代表所有网站均不可用。
- 自动切换默认关闭。启用后仅选择同地区、有新鲜成功测速结果且未运行的节点，复用失败代理原端口；原端口连接会中断，后续连接使用新出口。绑定任何浏览器记录的节点（包括已停止的记录）始终跳过自动切换；未知地区也不自动切换。新核心预检失败时保持原端口，切换启动失败时尝试恢复原节点。
- 订阅规则更改后，URL 订阅下一次刷新会重新下载完整内容，忽略旧的 ETag 缓存。手动内容订阅需重新导入原始内容应用新规则。没有过滤条件时保持全部导入。
- 订阅流量以提供方的 `subscription-userinfo` 响应头为准；未提供的字段不假定为零，没有新响应头时保留上次数据。
- SSE 状态流使用实例令牌请求头，不能通过查询参数认证；断线重连失败时由前端轮询兜底。服务端流连接会定期结束以便重新认证。

## WebDAV 拉取

先预览远端设备、时间与订阅、节点、浏览器及 Profile 差异，再确认覆盖。实际拉取校验预览的状态哈希；远端快照变化时需要重新预览。已有的本地并发变更检查、运行中 Profile 保护、加密与冲突处理继续生效。

## 验证入口

```bash
# Python 回归测试；推荐使用运行要求中的 Python 3.10 或更高版本。
python3 -m unittest discover -s tests
# Node 内置测试，覆盖既有认证、远程浏览器、内核上传、诊断与界面基础功能。
node --test tests/test_frontend_*.js
git diff --check
```
